防災統合ビューア JAPAN β

北海道から沖縄まで、場所を変えても同じルールで調べられる全国版です。全国共通の公式データは地図へ直接表示し、河川カメラや道路カメラなど外部利用向けの安定APIが確認できない情報は、現在見ている地点から公式サービスへつなぎます。

個人研究によるβ版です。 このビューアだけで避難判断を完結させないでください。避難指示、警報・注意報、道路規制、避難所の開設状況等は、国・都道府県・市区町村などの最新公式情報を優先してください。指定避難所ピンは「指定されている施設」であり、現在開設中を意味しません。

A / B / C データ設計と注意事項

A｜全国公式データ：外部利用可能な全国データとして確認できたものは、この地図から直接取得します。指定避難所・指定緊急避難場所は国土地理院のGeoJSONタイル、ハザードはハザードマップポータルのタイル、アメダスは気象庁公開データを利用します。

B｜全国オープンデータ：防災では誤情報による影響が大きいため、現時点では主要判断レイヤーとして採用していません。

C｜公式サービス連携：全国公式サービスは存在するものの、外部サイトから安定して直接表示するための公開仕様が確認できないものは、自前で内部APIを推測せず公式画面へ送ります。河川カメラ・水位・雨量は「川の防災情報」、道路カメラは国土交通省の全国入口を利用します。

外部サービス側の仕様変更や一時的な混雑により、取得・表示できない場合があります。
